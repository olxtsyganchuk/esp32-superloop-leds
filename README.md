# ESP32-Superloop-LEDs

Проєкт для ESP32 (Adafruit Metro ESP32-S3) на PlatformIO (Arduino framework, C++). Три світлодіоди блимають одночасно з різними незалежними інтервалами, без використання `delay()`.

## Що робить код

Програма керує трьома світлодіодами, кожен з яких перемикає свій стан у власному ритмі:

| Світлодіод | Пін | Інтервал перемикання |
|------------|-----|----------------------|
| Червоний | GPIO 4 | 200 мс |
| Жовтий | GPIO 5 | 500 мс |
| Зелений | GPIO 6 | 1000 мс |

Усе працює в єдиному безкінечному циклі `loop()` (архітектура **superloop**). На кожній ітерації код зчитує поточний час через `millis()` і для кожного світлодіода перевіряє, чи минув його інтервал. Якщо минув, то стан інвертується, а час останнього перемикання оновлюється.

### Особливості реалізації

- **Без `delay()`:** цикл ніколи не блокується очікуванням, тому всі три світлодіоди працюють паралельно і не заважають один одному.
- **Незалежні таймери:** для кожного світлодіода є своя змінна часу останнього перемикання (`prevMillis1..3`) та свій стан (`ledState1..3`).
- **Структура:** піни та інтервали зібрані в `struct Config` зі `static constexpr` константами, тому їх легко змінювати в одному місці.
- **Розширюваність:** щоб додати ще один світлодіод, достатньо додати пін, інтервал, пару змінних і ще один блок перевірки в `loop()`.

## Підключення

| Пін | Призначення |
|-----|-------------|
| GPIO 4 | Червоний світлодіод |
| GPIO 5 | Жовтий світлодіод |
| GPIO 6 | Зелений світлодіод |

Кожен світлодіод під'єднується через струмообмежувальний резистор 220 Ом до GND.
